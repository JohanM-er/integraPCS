Visual System Built From the Guide’s Minimal Token Set

This page intentionally uses the limited color, spacing, and typography scales described in the guardrails document. Notice how rhythm and hierarchy rely on repeating the same few values.

Product overview

Headlines, body copy, and captions all sit within a narrow range (text scales 0–2), so hierarchy is created mostly through weight and spacing. The layout breathes with padding multiples of 4, 6, and 8.

Buttons, badges, and cards repeat the same radius and shadow tokens, producing a very tight visual rhythm that is predictable but less expressive.

Cadence

Vertical spacing steps of 0.75rem and 1rem repeat across every module, creating consistent stacks but limiting contrast between sections.

Token Value
--spacing-3 0.75rem
--spacing-4 1rem
--spacing-6 1.5rem

Typography

The system limits headings to --text-scale-2. Subheads step down to --text-scale-1, while captions use --text-scale-0.

Without larger headline options, major section intros rely on spacing and color badges to stand out.

Color usage

The neutral palette collapses to two tones: background at neutral-50 and copy at neutral-900. Variation comes from the single brand accent, producing high contrast but few intermediate surfaces.

Key limitations surfaced by the demo:
  • Large hero headlines and jumbo spacing are unavailable, so top-level sections feel compact.
  • Only one surface tone prevents layered cards or subtle separators.
  • States (success, warning, error) cannot be expressed without introducing new tokens.
